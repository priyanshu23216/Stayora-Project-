<h1>Stayora 🏡</h1>

<p>
  <strong>Stayora</strong> is a property listing web application currently under development.
</p>

<p>
  The project aims to provide a platform where users can explore property listings and manage their own listings.
</p>

<p>
  I'm currently building this project to strengthen my full-stack web development skills, with a focus on backend development, database management, and server-side rendering.
</p>

<h2>🚧 Current Progress</h2>

<p>The basic CRUD functionality has been implemented.</p>

<ul>
  <li><strong>Create:</strong> Add new property listings.</li>
  <li><strong>Read:</strong> View all listings and individual listing details.</li>
  <li><strong>Update:</strong> Edit existing property information.</li>
  <li><strong>Delete:</strong> Remove property listings.</li>
  <li><strong>MySQL Integration:</strong> Store and manage listing data in a MySQL database.</li>
  <li><strong>EJS Templating:</strong> Dynamically render listing data.</li>
</ul>

<h2>🛠️ Tech Stack</h2>

<ul>
  <li><strong>Frontend:</strong> HTML, CSS, EJS</li>
  <li><strong>Backend:</strong> Node.js, Express.js</li>
  <li><strong>Database:</strong> MySQL</li>
  <li><strong>Other Tools:</strong> Method Override, UUID, Git &amp; GitHub</li>
</ul>

<h2>⚙️ Getting Started</h2>

<h3>1. Clone the repository</h3>

<pre><code>git clone YOUR_GITHUB_REPOSITORY_URL</code></pre>

<h3>2. Navigate to the project directory</h3>

<pre><code>cd Stayora</code></pre>

<h3>3. Install dependencies</h3>

<pre><code>npm install</code></pre>

<h3>4. Configure MySQL</h3>

<ul>
  <li>Start your MySQL server.</li>
  <li>Create the required database and listings table.</li>
  <li>Configure your database connection credentials in the application.</li>
</ul>

<h3>5. Run the application</h3>

<pre><code>node app.js</code></pre>

<p>
  Open <code>http://localhost:8080</code> in your browser
  (or the port configured in your application).
</p>
